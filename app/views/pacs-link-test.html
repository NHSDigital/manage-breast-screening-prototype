    {% set parametersHtml %}

    From the Vue PACS Client 12.2.8 activation guide. All of these go on the query string of the base URL, or inside an encrypted shs token.

    accession_number
    The study. Several joined with backslashes. A prefix plus * is a wildcard
    patient_id, issuer_of_patient_id
    Query filters. Also patient_first_name, patient_last_name, referring_physician_first_name and referring_physician_last_name. Wildcards allowed. Several matches show a list, one match loads
    study_instance_uid, series_instance_uid
    Load a specific study or series
    user_name, password, password_ecrypted, cfg_user
    PACS login. Without a password the viewer prompts
    server_name
    Archive Explorer title of the archive to load from
    close_on_exit, close_window
    true closes the browser window once the client has started. Worth trying with the new tab and popup styles
    start_monitor, num_of_monitors
    Which monitor the viewer opens on (0 is the left) and how many it uses
    load_study_with_last_presentation, key_images, load_significant_series, prior_query, locate_patient, load_and_dictate
    What and how to load
    shs
    AES-256 CBC encrypted form of the whole query, using a key shared with the PACS. Needs generating elsewhere and pasting in above

    The NativeBridge WebSocket plugin (default port 8283, commands JoinContext, ShowStudy, ShowStudyWithPID, CloseStudy, Heartbeat) is a separate route into the viewer and is not covered by this page yet.
