{% set stylesHtml %}
  • Same tab: a plain link, so this page is replaced. When delayed, location.assign instead.
  • New tab: a link with target=_blank. When delayed, window.open instead, which browsers usually block without a click.
  • Popup: window.open with a fixed size and a reused window name. May be blocked when delayed.
  • Fetch: a background GET with mode no-cors. Nothing opens in the browser and the response is opaque, so only reachable or not is known.
  • Hidden iframe: loads the URL in an invisible frame, so this page stays put. Its load event fires for error pages too.

    {% set parametersHtml %}

    Parameters the viewer accepts on the query string of the base URL, or inside an encrypted shs token.

    accession_number
    The study. Several joined with backslashes. A prefix plus * is a wildcard
    patient_id, issuer_of_patient_id
    Query filters. Also patient_first_name, patient_last_name, referring_physician_first_name and referring_physician_last_name. Wildcards allowed. Several matches show a list, one match loads
    study_instance_uid, series_instance_uid
    Load a specific study or series
    user_name, password, password_ecrypted, cfg_user
    Viewer login. Without a password the viewer prompts
    server_name
    Title of the archive to load from
    close_on_exit, close_window
    true closes the browser window once the viewer has started. Worth trying with the new tab and popup buttons
    start_monitor, num_of_monitors
    Which monitor the viewer opens on (0 is the left) and how many it uses
    load_study_with_last_presentation, key_images, load_significant_series, prior_query, locate_patient, load_and_dictate
    What and how to load
    shs
    AES-256 CBC encrypted form of the whole query, using a key shared with the viewer. Needs generating elsewhere and pasting in above

    The viewer also has a WebSocket route (default port 8283, commands JoinContext, ShowStudy, ShowStudyWithPID, CloseStudy, Heartbeat). This page does not cover it yet.
