Issues

The shared ways to show that a record has an issue, and an issue’s own status. Pages pass the episode, so an issue raised anywhere in a round shows everywhere in it. See docs/issues.md.

Has issue tag

Macro: issueTag(record, options) from _includes/issues/tag.njk. Shows only when an open issue links to the record. Leave the record out when the caller already knows. Uses has_issue in the misc tag vocabulary.
