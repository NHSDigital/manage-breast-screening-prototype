Issues

The shared ways to show that a record has an issue, and an issue’s own status. Pages pass the episode, so an issue raised anywhere in a round shows everywhere in it. See docs/issues.md.

Issue raised tag

Macro: issueTag(record, options) from _includes/issues/tag.njk. Shows only when an open issue links to the record. Leave the record out when the caller already knows. Uses has_issue in the misc tag vocabulary.

Open issues callout

Macro: openIssuesCallout(record, options) from _includes/issues/open-issues.njk. Each open issue’s description, who raised it and when, and a link to its page. Says image reading is on hold only while the issue’s episode is at mammograms or reading. Shows nothing when there are none. openIssueSummary(issue, options) from the same file shows one issue outside the callout.
