Filter panel

A search and filter column for an index page. The groups, selection and counts are data, usually built with the helpers in app/lib/utils/filter-list.js. See docs/filtering.md.

Macro: appFilterPanel(params)

Checkboxes with a search

{{ appFilterPanel({ action: "/style-guide/filter-panel", search: { name: "styleGuideSearch", label: { text: "Search by name" } }, groups: [ { name: "styleGuideStatus", legend: "Status", options: [ { value: "scheduled", label: "Scheduled" }, { value: "complete", label: "Complete" } ] } ], selected: { styleGuideStatus: ["scheduled"] }, counts: { styleGuideStatus: { scheduled: 12, complete: 3 } } }) }}
