Link

A plain link as a macro. Pass its params through the openInModal filter to open it in a modal when modal forms are switched on.

Macro: appLink(params)

Default

{{ appLink({ text: "View clinic", href: "#" }) }}

{% raw %}{{ appLink({
  text: "View clinic",
  href: "#"
}) }}{% endraw %}

For a destructive action

{{ appLink({ text: "Cancel appointment", href: "#", classes: "app-link--warning" }) }}

{% raw %}{{ appLink({
  text: "Cancel appointment",
  href: "#",
  classes: "app-link--warning"
}) }}{% endraw %}

Opening in a modal

{% raw %}{{ appLink({
  text: "Cancel appointment",
  href: cancelUrl
} | openInModal) }}{% endraw %}
