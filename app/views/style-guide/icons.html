Icons

Custom icons that are not part of the NHS icon set. For standard NHS icons, appIcon falls through to the nhsukIcon macro.

Macro: appIcon(name, params)

Custom icons

These are inline SVGs defined directly in the component.

{% set customIconRows = [] %} {% for icon in [ { name: "alert", usage: "Warning — triangular alert shape" }, { name: "warning", usage: "Caution — circular exclamation mark" }, { name: "information", usage: "Info — circular ‘i’ symbol" } ] %} {% set customIconRows = customIconRows | push([ { html: "" + icon.name + "" }, { html: appIcon(icon.name) }, { text: icon.usage } ]) %} {% endfor %} {{ table({ compact: true, striped: true, head: [ { text: "Name" }, { text: "Icon" }, { text: "Usage" } ], rows: customIconRows }) }}

{{ appIcon("information") }}{% endraw %}

Standard NHS icons (via fallback)

Any name not listed above is passed straight to nhsukIcon.

{% set standardIconRows = [] %} {% for iconName in ["tick", "cross", "chevron-right"] %} {% set standardIconRows = standardIconRows | push([ { html: "" + iconName + "" }, { html: appIcon(iconName) } ]) %} {% endfor %} {{ table({ compact: true, striped: true, head: [ { text: "Name" }, { text: "Icon" } ], rows: standardIconRows }) }} 
{% raw %}{{ appIcon("tick") }}
{{ appIcon("cross") }}
{{ appIcon("chevron-right") }}{% endraw %}

With accessible title

Pass params.title to add a <title> element and expose the icon to screen readers.

{{ appIcon("alert", { title: "Warning" }) }} Alert icon with screen-reader title "Warning"
