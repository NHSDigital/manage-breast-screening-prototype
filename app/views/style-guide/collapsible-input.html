Collapsible input

Hides an optional field behind a toggle link until it is needed. Without JavaScript the field shows as normal.

Macro: appCollapsibleInput(params)

Default

{% call appCollapsibleInput() %} {{ textarea({ name: "styleGuideComment", id: "style-guide-comment", label: "Comment" }) }} {% endcall %} 
{% raw %}{% call appCollapsibleInput() %}
  {{ textarea({
    name: "comment",
    id: "comment",
    label: {
      text: "Comment"
    }
  }) }}
{% endcall %}{% endraw %}

With custom link text

{% call appCollapsibleInput({ text: "Add a reason" }) %} {{ input({ name: "styleGuideReason", id: "style-guide-reason", label: "Reason" }) }} {% endcall %} 
{% raw %}{% call appCollapsibleInput({ text: "Add a reason" }) %}
  {{ input({
    name: "reason",
    id: "reason",
    label: {
      text: "Reason"
    }
  }) }}
{% endcall %}{% endraw %}
